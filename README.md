# 자유의 여신상 VR 360도 체험

- `index.html`: A-Frame 기반 VR1/VR2 전환 페이지
- `vr1-boat.jpg`: 배에서 본 자유의 여신상 파노라마
- `vr2-island.jpg`: 섬에서 본 자유의 여신상 파노라마

`index.html`과 두 JPG를 GitHub 저장소 최상위에 업로드한 후 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택하세요.

이미지는 제공된 AI 재구성 파노라마로, 원본 사진을 엄밀하게 스티칭한 실측 360도 영상은 아닙니다. 2:1 비율이지만 구면 투영 왜곡과 연결부를 실제 기기에서 확인해야 합니다.

A-Frame 1.8.0은 외부 CDN에서 불러오므로 최초 로딩 시 인터넷 연결이 필요합니다.
